# Moka Cafés

Site de uma cafeteria fictícia, feito como trabalho da disciplina de Front-end Web no curso de Sistemas de Informação da Universidade Positivo.

## Páginas

- **Início** (`index.html`): apresentação da cafeteria
- **Cardápio** (`cardapio.html`): bebidas e preços por tamanho
- **Pedido** (`pedido.html`): monta o pedido e guarda o histórico no navegador
- **Loja** (`loja.html`): vídeo e áudio da cafeteria
- **Contato** (`contato.html`): formulário de contato

## Tecnologias

- HTML5 e CSS3
- JavaScript
- Bootstrap 5 (no início, no cardápio e no pedido)
- localStorage, para salvar o histórico de pedidos

## Como abrir

1. Baixe o projeto em **Code > Download ZIP** ou clone o repositório:
   ```
   git clone https://github.com/camillypepplowrl/moka-cafes.git
   ```
2. Abra o arquivo `index.html` no navegador.

Não precisa instalar nada. O site funciona direto no navegador.

## Estrutura

```
moka-cafes/
├── index.html, cardapio.html, pedido.html, loja.html, contato.html
├── css/     estilos (Bootstrap, tema e estilo próprio)
├── js/      scripts de cada página
├── img/     imagens
├── video/   vídeo da loja
├── audio/   áudio da loja
└── doc/     documentação do trabalho
```
